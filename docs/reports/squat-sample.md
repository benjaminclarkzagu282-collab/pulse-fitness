## 范围与参考

沿用用户提供的写实人物及现有绑定，只制作一个独立徒手深蹲样板。正式 App 的八个原动作没有在本轮批量替换。

主要参考 [ACE Bodyweight Squat](https://www.acefitness.org/resources/everyone/exercise-library/135/bodyweight-squat/)：脚掌稳定、脚尖略外转、膝与脚尖方向协调、髋膝配合、接近大腿平行位置、控制起落。[Mayo Clinic Squat](https://www.mayoclinic.org/healthy-lifestyle/fitness/multimedia/squat/vid-20084663)作为中立背部与平稳运动的辅助参考；其九十度深度示范与 ACE 并不完全相同，本样板未声称精确复刻两者。没有下载、复制或重新分发参考视频/图片。

动画是按参考概念重新编排、针对人物尺寸求解的样板，仍不是动作捕捉或教练批准的教学素材。31 度躯干/胫骨倾斜等数值是此模型的制作参数，不是适用于所有人的标准。

## 改动

- 根据实际骨长构造髋、膝、踝位置，双脚保持地面支撑；单独调整颈部与手臂。
- 以掌部自身轴线校正手腕方向，避免继承原素材弯曲手腕的朝向。
- 六秒循环：0.5 秒准备、2.5 秒下蹲、0.5 秒底部停顿、2 秒起身、0.5 秒恢复。30 fps 逐帧烘焙，平滑起停。
- 独立网页同步前/侧视角，前视角可切背面；支持 0.25×、0.5×、1×、时间拖动、阶段定位、前后逐帧。

独立结构检查：1 个六秒 Exercise 动画、53 骨骼、61,515 三角面、9 张内嵌纹理；所有读取的数值有限、权重归一化、循环闭合。原四秒验证器的默认行为也通过检查。

负例：人为让人物整体中途横移 20 mm 再回原位，脚漂移回归检查正确失败，避免只查局部坐标漏掉整体滑动。

检查脚本不证明动作生物力学正确，不涵盖肌肉发力、人体个体差异或专业教学适用性；关节角度/皮肤观感仍需要人工审看。未做手机真机性能测试。

浏览器实测：桌面 1280×960 与手机模拟 390×844，双视角、前/背切换、阶段定位、暂停、速度选择、逐帧和进度条键盘定位均可操作；6 秒边界没有越界；手机无横向溢出且人物手脚完整。浏览器未记录错误。独立代码审查发现的时长报告及世界坐标检查缺口已修复。

## 文件与复现

- 编辑源：`../characters/03_深蹲动作样板/深蹲动作样板.blend`（相对项目根目录），含贴图和动画。
- 网页与模型：`web/squat-review.html`、`web/review/squat-v2.glb`。
- 数值与哈希：`docs/reports/squat-sample-verification.json`。
- 制作：Blender 后台运行 `tools/squat_sample.py -- --render`。
- 骨骼/皮肤检查：Blender 后台运行 `tools/check_squat_sample.py`；加 `-- --legacy` 重现旧错误，加 `-- --inject-root-slide` 执行应失败的负例。
- 结构检查：系统 Python 调用 `finalize_character_assets.validate(Path('web/review/squat-v2.glb'), texture_limit=2048, duration=6)`。Blender 自带 Python 没有 Pillow，因此结构/贴图检查在系统 Python 中执行。
