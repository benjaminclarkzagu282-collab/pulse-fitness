# 原生 24 动作库独立验收

验收工具为 `tools/original_rig/verify_native_library.py`，与动作求解器和构建器分离。通过表示下述技术检查通过，`coach_review_completed` 固定为 `false`，不代表教练审核、动作捕捉或人体解剖认证。

## 检查依据

- 从原始导入场景 `native-import-04/original-rig-staging.blend` 重新读取主体顶点权重、全部顶点组、81 个骨骼名称、父子关系和绑定矩阵。每个编辑源逐项比对，保留全部原始影响，原始最大影响数为 8。
- 肌肉层在未变形坐标中映射到原始主体或短裤表面，按原始顶点顺序消除接缝的邻点歧义，核对每个对应顶点的全部骨骼权重和原生 Armature 绑定。短裤本身的权重也与原始导入场景比对。检查实际导出模型中被网格使用的 `PULSE Muscle <region>` 材质，区域清单取自 `assets/muscles/catalog.json`。
- 按实际导出帧率播放编辑源的全部关键帧，而非重新调用求解器。检查骨矩阵与主体表面是否有限、原生父子关节原点距离、开始和结束循环、主体最低高度、足部／手部／膝部／前臂／背部实际表面接触以及支撑物范围。CAT 的显示尾端不作为实际肢段方向或连接依据。
- 检查各动作所需的哑铃数量、支撑器械、实际 28 mm 手柄尺寸、手柄附着中心与板片半径。在存在 `Native dumbbell L/R` 的动作中，采样手部顶点、三角形中心及边中点，测量手柄和板片穿透。
- 清空场景后重新导入最终 GLB，在每个关键帧及区间中点与编辑源逐顶点双向比对。30 FPS 为 361 个时刻，90 FPS 为 1081 个时刻，180 FPS 为 2161 个时刻。覆盖主体、短裤、全部肌肉层、器械和其他网格；允许 UV／材质缝处重复顶点，不允许缺失几何或超过误差门槛。
- 从 GLB 二进制时间采样器直接读取六秒长度，拒绝非有限、无序或错误的时间值；要求唯一名为 `Exercise` 的线性动画。报告中的时间标称值不参与这个判断。

浏览器资产采用完整原生 Skin 求值后的网格形态动画，因此 GLB 没有 `JOINTS_0` 或运行时 Skin 是预期行为。原生权重保真在编辑源上验证，导出保真通过实际几何重新导入比对验证。

## 容差

| 项目 | 门槛 |
| --- | --- |
| GLB 与编辑源最大顶点误差 | 0.5 mm |
| 循环首尾最大距离 | 0.6 mm |
| 原生关节原点距离变化 | 0.5 mm 加原始长度的 0.2% |
| 主体低于地面或进入支撑面 | 2.5 mm |
| 支撑表面抬离目标面 | 6 mm |
| 已固定表面支撑点水平位移 | 2 mm |
| 手柄／板片最大穿透 | 1 mm |
| 哑铃尺寸或握持中心偏差 | 0.5 mm |

地面容差包含已认可原生肩推／弯举中约 1.323 mm 的既有足部表面偏差；不会因此修改已认可模型。每次结果记录上述门槛和实际数值。

## 报告与发布门槛

完整运行在输入目录写入 `verification.json`。仅当 `motion_library.IDS` 的 24 个 ID 齐全、没有多余项、每项检查通过时，顶层 `passed` 才为 `true`。每项记录 GLB 和编辑源文件的 SHA-256；顶层记录构建报告及原始基准场景 SHA-256。模型、编辑源或相机范围报告在验收后改变时，打包器拒绝发布旧验收结果。

肩推和弯举同时与 `native-review-02` 的 GLB 字节哈希比较，确保保留已认可版本。输入目录未包含这两项时，验收直接读取该认可目录。指定 `--exercise` 的局部运行写入 `verification-<id>.json`；局部项目可以通过，顶层仍因未覆盖完整 24 项而保持 `false`，不能用于正式打包。

```sh
'/Applications/Blender.app/Contents/MacOS/Blender' --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/original_rig/verify_native_library.py -- --input-dir .build/original-rig/native-library-01
```

独立验收门槛的十项回归测试可以直接运行；其他构建工具测试依赖 Blender 自带的 NumPy：

```sh
python3 -m unittest discover -s tools/original_rig -p test_native_library_verification.py
```
