# 24 动作复核记录

软件检查保留原始骨架导出的动画资产，并确认本次无损交付与原资产哈希一致。技术验收不能代替教练审核，24 个动作当前均为 `pending_professional_review`。

## 实际复核流程

1. 打开 `action-acceptance.html`，选择与目标资产哈希对应的动作。
2. 在 `exercise-review.html?exercise=动作ID` 同时查看正面、侧面和关键阶段，检查准备、运动、返回全过程。
3. 核对动作版本、接触支撑、肩肘/髋膝方向、躯干控制及器械握持。来源用于方向参考，并非对本动画的逐帧认证。
4. 记录审核人真实姓名、资质、日期、关键阶段和具体问题；填写通过/需修改及证据引用。保存记录后仍须由发布负责人核实身份和证据，才能更新专业审核状态。
