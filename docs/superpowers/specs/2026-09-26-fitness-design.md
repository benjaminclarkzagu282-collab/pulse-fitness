# PULSE 动态健身首版

用户已批准六页视觉方案并要求开始：Flutter；炭黑、暖白、荧光绿；自定义训练计划、多种动作3D示范、健康饮食、每日统计评分、根据近期训练安排下次训练与饮食。

## 交付范围
五个导航页（今天、计划、动作、饮食、记录）与独立跟练页；响应式布局；中文；本地持久化。Flutter web先验证，保留Android/iOS工程。当前主机Android SDK、完整Xcode不可用，因此手机构建不作为已验证交付。

## 行为与数据
- 计划可修改目标、可用分钟、每周日期、器材、动作顺序、组数、次数、休息；添加删除替换动作，空计划显示引导。
- 动作库至少8种不同动作，按部位和器材搜索筛选、收藏、查看动作要点并加入计划。实际3D模型可旋转缩放与播放暂停；列表使用本地渲染缩略图。模型是运动示意，非医学动作评估。
- 跟练按组记录完成，保留休息计时、暂停、跳过休息、主观疲劳反馈；防止重复记完成组。用时间戳计算计时，离开页面自动释放资源。次数为计划目标、手动完成组，不伪装摄像头计数。
- 四餐计划、替换与份量调整、偏好（均衡/素食）及过敏食材过滤、饮水记录；记录、撤销后统计一致。营养为计划估算。热量目标用户设定，不按低摄入奖励评分，不以加练自动削减饮食。
- 每日完成分=训练完成率60%+餐食记录完成率30%+饮水目标完成率10%，各项0至100，四舍五入；空目标不除零。无数据不伪造历史，图表明确空白天。成绩是计划执行情况而非健康诊断。
- 推荐基于最近7天真实日志（完成率、最近训练部位、疲劳），高疲劳或低完成率减少训练量；否则切换主要部位并保持适度训练。根据用户饮食偏好与近期训练提供次日餐食组合及原因；预算/营养目标保留用户设定。建议先预览，点击采用后保存到次日安排，不覆盖今天和历史。
- 新用户从零记录开始，预置动作和餐食是可编辑内容。数据按日期隔离，JSON持久化可重启恢复；存储失败向用户报告。

## 架构
ChangeNotifier应用状态+可序列化领域模型；shared_preferences本地存储；拆分页面和共享组件。ModelViewer承载GLB，3D渲染与状态管理解耦，初始化/失败有明确提示。

## 验证
业务测试覆盖空计划评分、重复组记录、日期隔离、持久化、疲劳分支与次日采纳；widget测试覆盖导航和编辑保存；真实浏览器检查3D加载动画、手机尺寸溢出、编辑后统计变化和刷新持久化；flutter analyze、flutter test、flutter build web。
